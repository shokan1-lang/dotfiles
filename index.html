Policies

Generative AI Use

This course is about configuring and directing generative AI coding agents. Using them is the central subject matter. What remains non-negotiable is transparency and demonstrated understanding.

Permitted Use

  • Writing, refactoring, and debugging code
  • Planning and executing spec-driven workflows
  • Exploring concepts, generating examples

Secrets Hygiene

Never commit API keys, tokens, or passwords to any repository. Keep secrets in environment variables or .env files.
